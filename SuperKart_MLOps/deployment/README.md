# SuperKart Sales Forecast

An interactive Streamlit application for predicting
product-store sales revenue.

## Machine Learning Model

The application loads the trained model from:

ranadipmajumdar/Superkart_MLOps-model

## Input Features

The application accepts:

- Product Weight
- Product Sugar Content
- Product Allocated Area
- Product Type
- Product MRP
- Store Establishment Year
- Store Size
- Store Location City Type
- Store Type

## Output

The application returns the predicted
Product Store Sales Total.
